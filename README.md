# Job Search Copilot

An AI-powered Python application designed to help job seekers analyze job descriptions, identify relevant skills, compare opportunities, and organize their job search.

## Current Features

- Accepts a job description from the user
- Performs basic text analyses as the foundation for skill extraction

## Planned Features

- Detect technical skills in job descriptions
- Save interesting job opportunities
- Compare job requirements with a résumé
- Use AI to explain job-match results
- Generate targeted interview questions
- Track application progress and follow-up dates
- Search for current job listings through an approved data source

## Project Goals

This project is being developed to strengthen my skills in:

- Python
- AI API integration
- Prompt engineering
- JSON and structured data
- SQLite
- Automated testing
- Git and GitHub
- Responsible AI development

The application will not invent qualifications or add experience that a user does not have.
